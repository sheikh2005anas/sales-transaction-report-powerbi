# Sales and Transaction Report by Period

## Project Overview

This Power BI dashboard provides a comprehensive analysis of sales and transaction performance across different time periods. The report helps businesses monitor revenue trends, transaction volumes, customer activity, and product performance using interactive visualizations and dynamic filters.




## Objectives

* Analyze sales performance over time.
* Track transaction counts and revenue trends.
* Identify top-performing products and categories.
* Monitor monthly, quarterly, and yearly growth.
* Support data-driven business decisions.



## Dashboard Features

### Executive Summary

* Total Sales
* Total Transactions
* Average Transaction Value
* Total Customers



### Time-Based Analysis

* Monthly Sales Trend
* Quarterly Performance Comparison
* Year-over-Year Growth Analysis

### Product Performance

* Top Selling Products

### Customer Insights

### Interactive Filters

* Date Range Selection
* Product Category Filter

* Region Filter
